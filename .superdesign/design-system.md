# Shop concept system — provisional brand Luma
Purpose: tech gadget/accessory portfolio demo, showcased as project 02 after Donewell on /projects/. This is design exploration ONLY, no backend integration or implementation.
The shop has independent pages, navigation and styles. Existing portfolio/workshop source is integration context, NOT a palette constraint. Preserve Donewell; do not redesign it.
## Shared brief for exactly three storefront directions
Provisional brand: Luma, text wordmark, no existing shop logo asset. No unrelated portfolio/company logos or profile photos should be used.
Desktop first with responsive mobile layout. Offer catalog categories Audio, Desk, Power, Wearables. Hero: 'Good tech. Great energy.' Feature wireless headphones, earbuds, portable speaker, magnetic charging stand, mechanical keyboard, USB-C hub. Use the same fictional products and NGN illustrative prices across variants. Prices are provisional demo content.
Include shop navigation, product search, category filter pills, Google sign-in entry, cart count, a hero gadget with compelling image/art, featured collection with product cards, add-to-cart controls, a small demo disclosure, and footer with Back to projects. At least six product cards. No fake ratings, customer numbers or fabricated endorsements.
## Visual principles
Very unique, colorful iOS-inspired glass, Gemini-inspired bright flowing colors without using Google/Gemini branding. Rich blue, violet, cyan, pink gradients; frosted translucent panels; fine bright borders; soft shadows; sculptural gadget imagery; readable dark ink or high-contrast white text. Avoid bland generic SaaS hero layouts. No excessive glass behind long text. Typography clean sans with clear hierarchy, strong product focus. Minimum readable text, visible keyboard focus, adequate contrast, reduced motion, responsive product grid. Use public HTTPS imagery if available; no local paths or broken images.
## Flow constraints
Browse freely; sign in using Google for persistent cart and demo checkout. Simulated order only, no card collection or real payment. Dedicated checkout and account/order history planned. Supabase persists catalog, profiles, carts and orders; server validates totals; Mailgun sends clearly labeled demo confirmations. Do not imply these integrations work inside visual drafts.
## Three directions
1 Aurora Flow: pearl base, luminous liquid aurora ribbons, asymmetrical editorial hero and luminous floating glass objects.
2 Prism Playground: expressive saturated color pools, playful rounded tiles and oversized gadget arrangements, still polished and legible.
3 Midnight Glass: ink/navy base, bright chromatic light refractions and premium sculptural lighting, restrained glass showroom.
